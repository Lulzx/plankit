# Opportunity

## The shift

OpenAI's **Sign in with ChatGPT** gained *plan usage*: with the user's consent, an app's AI requests are billed to the user's own ChatGPT Plus or Pro plan instead of the developer's API key. It entered beta in July 2026 and was expanded at DevDay (late September 2026).

For now, plan usage is self-serve only for **open-source projects and personal apps that run locally**. Commercial and hosted apps are on a waitlist.

## Why it matters

- **No inference cost for the developer.** An indie open-source app can ship real AI features with no billing, no API key and no risk of cost overruns.
- **No setup for the user.** They sign in with the ChatGPT account they already pay for. No API key, no second bill.
- **It undercuts paid AI tools.** Many $10–20/month tools mainly charge to cover API costs. A free, local, open-source version now costs its developer nothing to run.

## Why it's still open

Few builders have acted on it. Partner lists show only a handful of open-source apps using plan usage (OpenClaw, OpenCode, Pi, T3). Most other signs of interest are GitHub issues asking maintainers to add it.

## Our angle

Make plan usage trivial and legally clean for open-source developers, through a permissively licensed SDK. Prove it with an example app people actually want. See [Competition](competition.md) for why "legally clean" is the wedge.
